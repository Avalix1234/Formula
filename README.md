# Formula

Стартовый проект школьного справочника Formula (5–11 классы).

## Что уже есть
- Выбор класса, предмета и темы.
- Поиск по доступным примерам формул.
- Стартовые примеры формул и некоторые интерактивные расчёты.
- Избранное, история открытых формул, тёмная/светлая тема.
- Сохранение настроек на устройстве и работа интерфейса офлайн.

## Важно
Это начальная рабочая заготовка, а не полный справочник на 300+ формул. Наполнение должно быть последовательно расширено и проверено по актуальной российской школьной программе и конкретным учебным материалам. Сейчас не все предметы и классы заполнены.

## Android
Проект использует Capacitor. GitHub Actions workflow пробует создать Android-проект, собрать debug APK и приложить его к запуску workflow.
